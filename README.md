# מעקב מד"ס — מכינת יפו

אתר לתיעוד ההתקדמות של חניכי המכינה במד"ס (אימוני כוח, 3 בשבוע לאורך השנה).
רץ על **Netlify**: האתר ב-`public/`, השרת ב-`netlify/functions/api.mjs`, והנתונים נשמרים ב-**Netlify Blobs**.

## מי רואה מה

כל אחד נכנס עם **קוד**, והקוד קובע מה מותר לו. הבדיקה נעשית בשרת.

| מי | הקוד | מה אפשר |
|---|---|---|
| חניך | 8 ספרות, נוצר כשהאחראי מוסיף אותו | רואה רק את האימונים והתוצאות שלו, מזין תוצאות, רואה גרף התקדמות |
| אחראי קבוצה | 8 ספרות, אחד לכל קבוצה | רק הקבוצה שלו: הוספת חניכים, רמה וסטטוס, הגדרת אימונים, לוח מעקב |
| צוות | 10 ספרות | כל הקבוצות, סקירה כללית, פרסום אימון לכמה קבוצות בבת אחת |

- **שנה א**: 12 קבוצות. **שנה ב**: 2 קבוצות.
- **רמות**: א (טובים), ב (בינוניים), ג (מתקשים). אימון אפשר לייעד לכל הרמות או לרמה אחת.
- **סטטוסים**: פעיל, פצוע, פטור, עזב. ממוצעי הקבוצה כוללים רק פעילים ופצועים.

## הפעלה ב-Netlify (פעם אחת)

1. ב-[app.netlify.com](https://app.netlify.com): **Add new site ← Import an existing project ← GitHub**, ובוחרים את הריפו הזה.
2. **Branch to deploy**: הענף שעליו האתר נמצא. שאר ההגדרות נקראות מ-`netlify.toml`.
3. לפני הפריסה (או אחריה, ב-**Site configuration ← Environment variables**) מוסיפים משתנה:
   - Key: `MDS_CODES`
   - Value: שורת הקודים, בפורמט:
     ```
     STAFF:<קוד צוות>;A1:<קוד>;A2:<קוד>;...;A12:<קוד>;B1:<קוד>;B2:<קוד>
     ```
     `A` זו שנה א ו-`B` שנה ב. המספר הוא מספר הקבוצה.
4. **Deploy**. אחרי שינוי במשתנה צריך **Deploys ← Trigger deploy**.

מסד הנתונים (Netlify Blobs) נוצר אוטומטית, בלי הגדרות נוספות. כל push לענף מעדכן את האתר.

**את הקודים לא שומרים בריפו**, כי הוא ציבורי. הם נמצאים רק במשתנה הסביבה ב-Netlify.
כדי להחליף קוד של אחראי או צוות, עורכים את `MDS_CODES` ומפעילים פריסה מחדש.

## שימוש

1. **אחראי קבוצה** נכנס עם הקוד שלו ← לשונית **חניכים** ← מדביק שמות (שם בכל שורה) ← **הוספה**.
   כל חניך מקבל קוד. כפתור **העתקת רשימת קודים** מעתיק את כל השמות והקודים, כדי לשלוח בוואטסאפ.
2. בלשונית **אימונים** האחראי מגדיר את 3 המד"סים של השבוע (מד"ס 1, 2, 3): תאריך, נושא, רמה, תרגילים, ומה החניך מזין בכל תרגיל (חזרות, זמן ריצה, זמן החזקה, ק"ג, מטרים). **שכפול** מעתיק אימון קיים לתאריך חדש.
3. **החניך** נכנס עם הקוד שלו (הדפדפן זוכר אותו) ורואה את המד"ס של השבוע. הוא מזין תוצאה לכל תרגיל ורואה את ההתקדמות שלו.
4. בלשונית **הקבוצה** האחראי רואה מי השלים, מי חסר ואחוזי השלמה, ולחיצה על חניך פותחת את הגרפים שלו.

## פיתוח מקומי

```bash
npm install
MDS_CODES="STAFF:1111111111;A1:22222222" npm run dev
```

האתר עולה ב-`http://localhost:8888`, והנתונים נשמרים בתיקייה `.data/`.

## קבצים

```
public/                   האתר (HTML, CSS, JS, לוגו)
netlify/functions/api.mjs  השרת: הרשאות לפי קוד וכל הפעולות
netlify/lib/store.mjs      גישה ל-Netlify Blobs (או לקבצים בפיתוח)
scripts/dev-server.mjs     שרת פיתוח מקומי
netlify.toml               הגדרות Netlify
```
