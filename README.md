# מעקב מד"ס — מכינת יפו

אתר לתיעוד ההתקדמות של חניכי המכינה במד"ס (אימוני כוח, 3 בשבוע לאורך השנה).

- **שנה א**: 12 קבוצות. **שנה ב**: 2 קבוצות.
- כל חניך משויך לרמה: **א** (טובים), **ב** (בינוניים), **ג** (מתקשים).
- **הצוות מגדיר את המד"ס** (תרגילים ויעדים), והוא מופיע לחניכים. החניך רק מזין את התוצאה שלו.

## תפקידים

| מי | איך נכנסים | מה רואים |
|---|---|---|
| חניך | בוחר את השם שלו (פעם אחת) | המד"ס של השבוע, הזנת תוצאות, ההתקדמות האישית |
| אחראי קבוצה | **קוד קבוצה** (6 ספרות) | רק את החניכים של הקבוצה שלו: מי השלים, מי חסר, גרפים |
| איש צוות | **קוד צוות** | כל הקבוצות, סקירה כללית, הגדרת אימונים, שינוי רמה, קודי האחראים |

הקודים נבדקים בשרת (Apps Script). נתוני הקבוצות לא נשלחים לדפדפן בלי קוד תקין.

## הגדרת מד"ס (צוות)

בלשונית **צוות ← אימונים** בוחרים:
- תאריך ושם לאימון
- למי הוא מיועד: כל השנים או שנה א/ב, כל הרמות או רמה א/ב/ג. אפשר לתת אימון שונה לכל רמה.
- תרגילים. לכל תרגיל בוחרים מה החניך מזין:
  - **חזרות**, למשל שכיבות סמיכה
  - **זמן ריצה/מקטע** (פחות = טוב), למשל ריצת 3 ק"מ
  - **זמן החזקה** (יותר = טוב), למשל פלאנק
  - **ק"ג** או **מטרים**
- יעד או הנחיה לכל תרגיל (לא חובה), למשל "3×15" או "מתחת ל-15:00".

כפתור **שכפול** מעתיק אימון קיים לטופס, כדי לחזור עליו בתאריך אחר.

## הפעלה

האתר סטטי (HTML/JS) והנתונים נשמרים ב-Google Sheets.
כל עוד `API_URL` ב-`config.js` ריק, האתר רץ **במצב הדגמה** עם 150 חניכים מדומים שנשמרים רק בדפדפן.

### 1. הקמת הגיליון וה-API

1. צרו Google Sheet חדש (למשל "מעקב מד״ס").
2. בתפריט: **תוספים ← Apps Script**.
3. מחקו את התוכן והדביקו את כל הקובץ `apps-script/Code.gs`. שמרו.
4. בחרו את הפונקציה `setup` ולחצו **הפעלה** (Run). אשרו את ההרשאות.
   נוצרים הטאבים `Trainees`, `Workouts`, `Logs` ו-`Codes`. **קוד הצוות** מודפס ביומן הביצוע (Execution log). קודי האחראים נמצאים בטאב `Codes`.
   כדי לבחור קוד צוות משלכם: **הגדרות הפרויקט ← Script Properties ← `STAFF_CODE`**.
5. **פריסה ← פריסה חדשה** (Deploy → New deployment) ← סוג: **אפליקציית אינטרנט** (Web app):
   - Execute as: **Me**
   - Who has access: **Anyone**
6. העתיקו את כתובת ה-Web App (מסתיימת ב-`/exec`).

### 2. חיבור האתר

הדביקו את הכתובת ב-`config.js`:

```js
API_URL: 'https://script.google.com/macros/s/XXXXXXXX/exec',
```

### 3. פרסום ב-GitHub Pages

ב-GitHub: **Settings ← Pages ← Source: Deploy from a branch**, בחרו את הענף ואת התיקייה `/ (root)`.
אחרי דקה-שתיים האתר יהיה זמין בכתובת `https://<user>.github.io/67/`. את הקישור שולחים לחניכים.

### טעינת רשימת חניכים מראש (לא חובה)

חניכים יכולים להירשם בעצמם, אבל אפשר גם למלא ישירות בטאב `Trainees`:

| id | name | year | squad | level | createdAt |
|---|---|---|---|---|---|
| t001 | ישראל ישראלי | א | 3 | ב | |

`id` — כל מזהה ייחודי. `year` — א/ב. `squad` — 1-12 בשנה א, 1-2 בשנה ב. `level` — א/ב/ג.
אפשר לשנות רמה של חניך מתוך האתר (עם קוד צוות: לשונית אחראי קבוצה ← לחיצה על החניך) או בעמודת `level` בגיליון.

## חשוב לדעת

- **לחניכים אין סיסמה.** חניך בוחר את שמו מרשימה, כך שטכנית אפשר להזין תוצאה בשם של מישהו אחר. נתוני הקבוצות והסקירה מוגנים בקודים.
- קוד שדלף? **צוות ← קודי אחראים ← החלפת כל הקודים**. את קוד הצוות מחליפים ב-Script Properties.
- לאחר עדכון `Code.gs` צריך **פריסה ← ניהול פריסות ← עריכה ← גרסה חדשה**, כדי שהכתובת תישאר זהה.
- הנתונים כולם בגיליון, כך שאפשר לסנן, לייצא ולבנות גרפים ישירות ב-Sheets.
